## Summary

The Current Dental Terminology (CDT) is a dental procedure code set maintained by the American Dental Association and updated annually. CDT codes are used on dental claims forms (ADA Dental Claim Form) and are required for insurance billing in the United States. Each code has a specific descriptor, and using the correct code is essential for proper reimbursement, audit defense, and coding compliance.

This reference covers the most frequently used CDT codes in a general dental practice, organized by category. Note that CDT codes describe procedures, not diagnoses; the combination of procedure code + diagnosis/clinical documentation determines coverage.

## Contraindications

- **Using D1110 (prophylaxis) for a periodontitis patient**: This is both a clinical error and potential insurance fraud; periodontitis patients require D4341/D4342 or D4910.
- **Billing D2950 (core buildup) without documentation of missing walls**: Core buildup must be clinically justified; a tooth with adequate coronal structure does not require a core.
- **Billing D0180 without 6-point periodontal charting**: D0180 requires a comprehensive periodontal evaluation; the chart must support the code.

---

## Evidence Notes

- **CDT annual updates**: CDT codes change annually; practices must use the current year's CDT (CDT 2024 as of this writing) and update their fee schedules accordingly.
- **Code bundling**: Some insurers bundle codes that should be separately billable (e.g., D2950 core with crown); appeal with documentation of clinical necessity.
- **Frequency limitations**: Most plans have frequency limitations (e.g., 1 crown per tooth per 5 years; BWs every 12 months); exceeding these without pre-authorization leads to denial.
